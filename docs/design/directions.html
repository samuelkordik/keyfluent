Keyfluent: design directions

Three ways to give Keyfluent an 80s and early-90s terminal feel. All three share the same base: Monaspace Argon as the default font (all five Monaspace faces included, plus your own font), and a theme engine with Tomorrow Night Bright as the default. They differ in layout, density, type voice and signature move. Pick one, or combine parts. Nothing is built yet.

Mock content is real: the first Basics card ("Split this pane side by side"), card 3 of a 17-card session, with the prefix just pressed.

A · Mainframe

The whole app is a text-mode program: every screen is drawn as a character grid with box frames, like a DOS-era tool or a BBS.

Mood
immersive, crisp, nerdy
Layout
Full-window frame; menus as highlighted lists; function-key bar at the bottom (F1 Help, F2 Today, F3 Progress, F4 Preferences; outside practice only)
Density
compact: one 13–14 px grid, 1 row = 1 line
Type
Argon only, at one size. The intent line is double-width and bold, like a DEC double-size line
Color
Theme as-is. Frames in the comment color; selection as an inverse bar; one yellow marker
Shape / motion
Zero radius, double-line outer frame. Motion: a blinking cursor, nothing else
Signature move
No visible GUI widgets at all: the app looks like it runs inside the terminal it teaches
Best for
People who already love terminals; maximum nostalgia
Trade-off
Hardest for a beginner who has never used a terminal. Every control is a custom egui widget (more build work, accessibility labels by hand). Preferences forms feel cramped.

B · Workstation

A normal desktop app (sidebar, panels, buttons) dressed like an early-90s Unix workstation, with the terminal as the hero.

Mood
calm, capable, tactile
Layout
Left rail (Today, Progress, Preferences); content; goal picture in a side panel. The rail hides during practice
Density
comfortable: base 15 px, 8 / 12 / 16 px spacing
Type
Argon for UI and the terminal; Xenon (slab) for headings and the intent; ratio 1.25
Color
Theme surfaces (background, current line) + one accent from the theme's blue for primary and focus; status colors only for grades (always with a word)
Shape / motion
3 px radius, 1 px borders, no shadows. Motion for feedback only: keycap press, result flash
Signature move
Chunky raised keycaps, like an old mechanical keyboard, used for every key shown (intro, strip, "Shortest" hint)
Best for
Complete beginners, and the Preferences and Progress screens. The easiest build in egui
Trade-off
The least "fun" of the three. The retro feel lives in the details (font, keycaps, theme), not the structure

Practice, 1000 × 700 window (rail shown here for context; it collapses during practice)

C · Boot screen

Early-90s home computer and arcade energy: big display type, a rainbow stripe, a score line after every card.

Mood
playful, bold, warm
Layout
Centered single column. Today is a title screen ("Press Enter to start"); Progress and Preferences open from it as full screens
Density
spacious: base 16 px, big headings, generous margins
Type
Mixes Monaspace faces: Krypton (wide, heavy) for display, Argon for body and the terminal, Radon (handwriting) for teach notes
Color
All six theme accents in use: each category owns one (Basics blue, Copy mode green, Sessions purple, Layout orange); the stripe uses them all
Shape / motion
Square corners, dashed rules. Motion: a score count-up on the result flash (off with reduced motion)
Signature move
The result flash as an arcade score line: GOOD · 1.6 s / target 2.0 s; and the six-color stripe
Best for
Making short daily practice feel like play
Trade-off
Edges toward "gamified", which the spec warns against (no guilt, no nagging). Big type crowds the 1000 × 700 minimum. Heavy color use makes weaker themes look garish, and every category color needs a contrast check in every theme

Practice (result flash after success), 1000 × 700 window

Shared by every direction: themes and fonts

Each theme sets the simulated terminal's colors and the app's colors at once. Shipped themes are tested content: a test fails any theme whose text, muted text, focus or grade colors fall under WCAG AA. Where an original theme color fails (light Tomorrow's comment gray, most Solarized pairs), the theme ships with the nearest passing shade of the same hue. A preference can show the exact original colors instead. "Follow system" picks your chosen dark theme or light theme.
