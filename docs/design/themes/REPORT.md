# Keyfluent themes: WCAG AA report

_Generated by `build_themes.py`; do not edit. Source for the website's Themes page and the About screen credits._

Every theme is checked against WCAG 2.2 AA: body and secondary text at least 4.5:1 on the background and panels, colored text at least 4.5:1 on the background, borders and the focus ring at least 3:1. Where an original color falls short, Keyfluent uses the nearest color with the same hue and saturation that passes (only lightness changes). **Preferences → Appearance → Use original theme colors** turns these changes off.
